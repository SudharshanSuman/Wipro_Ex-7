# Wipro Java Ex-7: Product Inventory Management System

## Aim
To develop a Product Inventory Management System using Java Server Pages to handle product details, calculate the total inventory value, determine the stock status, and display the inventory report dynamically.

## Description
This exercise involves developing a web application using:
- **Java Server Pages (JSP)** - For dynamic web content generation

### Program Files:
- **inventory.jsp** - Main inventory management page
- **product.jsp** - Product details processing page

### Features:
- JSP form handling
- Product detail retrieval
- Total inventory value calculation
- Stock status determination
- Dynamic generation of product inventory report in a formatted HTML table

## Result
The Product Inventory Management System was successfully developed using Java Server Pages (JSP). The application was implemented and executed successfully in Eclipse with Apache Tomcat, demonstrating JSP form handling, product detail retrieval, total inventory value calculation, stock status determination, and dynamic generation of the product inventory report in a formatted HTML table.
